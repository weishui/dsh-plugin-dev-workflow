## 本轮踩坑

1. **npm 2FA 是 `auth-and-writes`**：CLI 写操作只认 `npm publish --otp=<6 位>`，没有浏览器通道。
   首次 `npm publish` 直接 `EOTP`；最终由负责人本人在终端带 OTP 发布。
2. **发布时的 tarball 与 tag 有一处不一致**：实际发出去的 0.1.0 里没有 `CHANGELOG.md`
   （`package.json files` 是加 changelog 之前的版本），仓库与 tag 上有。功能代码一致，只差这一份文档。
   下次发版（0.1.1 或后续）会自然对齐；不要覆盖重发 0.1.0。
3. **awesome 的 1 天仓库年龄门槛**：仓库 `2026-10-31T07:51Z` 创建，PR 提交时不足 24h，
   submission gate 会先给 repo-age 红；按 contributing.md 该结论会自动重跑，
   满 24h 后自行通过，无需推空提交。
4. **市场条目 icon**：条目里 `icon:` 只接受 GitHub 托管的位图，SVG 会被拒。
   本轮先省略（回退作者头像）；要卡片图标需另出 180px PNG 再补。
