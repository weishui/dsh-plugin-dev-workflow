## 本轮踩坑

1. **0.2.0 没上过 npm**：上一版只发了 GitHub Release，npm publish 卡在 OTP。本次直接发 0.2.1，
   semver 允许跳过未发布的 0.2.0，安装 `dsh-plugin-dev-workflow@latest` 即得全部能力。
2. **SVG 里 U+2192 箭头会与相邻文字叠排**：Chrome 直接渲染 SVG 时箭头字形占用窄，`→` 紧贴
   后文会重叠。解法是把易撞行的元素垂直错位（右侧流程行 y=286 vs 步骤编号 y=372），渲染后放大目检。
3. **首图不要用阴影/渐变/彩色强调条**：负责人对 0.2.0 看板的反馈同样适用于 README——
   「ai 味」的视觉语言要避免，编辑式排版是本项目已验证两次的审美路线。
